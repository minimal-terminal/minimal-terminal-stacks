# Jellyfin\n\nJellyfin is a free and open-source media system that puts you in control of managing and streaming your media. It's an alternative to proprietary media solutions, focusing on privacy and user freedom. With Jellyfin, you can organize your movies, TV shows, music, and photos, and then stream them to any device, anywhere, with a beautiful and intuitive interface.\n\n## Prerequisites\n\nEnsure you have Docker and Docker Compose installed. You will need to create a dedicated volume for Jellyfin's configuration and a mount point for your media files.\n\n-   **`./jellyfin/config`**: This directory will store Jellyfin's configuration, metadata, and database.\n-   **`./jellyfin/cache`**: This directory will store Jellyfin's transcode cache.\n-   **`/path/to/your/media`**: This is where your actual media files (movies, TV shows, music) are located on your host system.\n\n## Docker Compose Script\n\n```yaml\nversion: '3.8'\n\nservices:\n  jellyfin:\n    image: jellyfin/jellyfin:latest\n    container_name: jellyfin\n    network_mode: host # Recommended for UPnP/DLNA and easier port management, adjust if conflicts exist\n    volumes:\n      - ./jellyfin/config:/config\n      - ./jellyfin/cache:/cache\n      - /path/to/your/media:/media # Be sure to replace /path/to/your/media with your actual media path\n      # Optional: For hardware transcoding (e.g., Intel Quick Sync Video)\n      # - /dev/dri:/dev/dri\n    environment:\n      - PUID=1000 # Replace with your user ID (id -u)\n      - PGID=1000 # Replace with your group ID (id -g)\n      - TZ=Etc/UTC # Replace with your timezone, e.g., America/New_York\n    restart: unless-stopped\n    # If not using network_mode: host, uncomment and configure ports:\n    # ports:\n    #   - 8096:8096 # Web UI\n    #   - 8920:8920 # HTTPS (if enabled)\n    #   - 1900:1900/udp # DLNA (if enabled)\n    #   - 7359:7359/udp # Auto-discovery (if enabled)\n```\n
