# Linkwarden\n\nLinkwarden is a self-hosted, open-source bookmark manager that allows you to save, organize, and archive web pages and links. It's a robust solution for preserving your digital finds, ensuring content remains accessible even if the original source disappears, and providing a powerful search and tagging system for your personal web archive.\n\n## Prerequisites\n\nBefore deploying Linkwarden, ensure you have Docker and Docker Compose installed on your system. You will also need to choose strong, unique passwords for the PostgreSQL database and a long, random secret for `NEXTAUTH_SECRET`.\n\n## Docker Compose Script\n\nThis `docker-compose.yml` sets up Linkwarden alongside a PostgreSQL database, ensuring persistent storage for both your application data and database. This configuration is suitable for a home server or NAS environment.\n\n```yaml\nversion: '3.8'\n\nservices:\n  db:\n    image: postgres:15-alpine\n    restart: unless-stopped\n    environment:\n      POSTGRES_DB: linkwarden\n      POSTGRES_USER: linkwarden\n      POSTGRES_PASSWORD: your_strong_db_password_here # <-- CHANGE THIS\n    volumes:\n      - ./data/linkwarden_db:/var/lib/postgresql/data\n\n  linkwarden:\n    image: ghcr.io/linkwarden/linkwarden:latest\n    restart: unless-stopped\n    ports:\n      - "3000:3000" # Host_Port:Container_Port - Change host port if 3000 is in use\n    environment:\n      DATABASE_URL: postgresql://linkwarden:your_strong_db_password_here@db:5432/linkwarden # <-- USE THE SAME DB PASSWORD\n      NEXTAUTH_SECRET: your_very_long_and_random_secret_for_nextauth # <-- GENERATE A LONG, RANDOM STRING\n      NEXT_PUBLIC_APP_URL: http://localhost:3000 # <-- CHANGE TO YOUR DOMAIN/IP FOR PRODUCTION ACCESS\n      # Optional: Set initial admin user on first run. Remove or comment out these lines after the first successful login for security.\n      # INITIAL_ADMIN_EMAIL: admin@example.com # <-- CHANGE THIS\n      # INITIAL_ADMIN_PASSWORD: your_initial_admin_password # <-- CHANGE THIS\n    volumes:\n      - ./data/linkwarden_app:/app/data # For uploaded files, screenshots, etc.\n    depends_on:\n      - db\n```\n\n### How to Deploy\n\n1.  **Save the file**: Save the content above as `docker-compose.yml` in a new directory (e.g., `linkwarden`).\n2.  **Create data directories**: The script will automatically create `./data/linkwarden_db` and `./data/linkwarden_app` relative to your `docker-compose.yml` file.\n3.  **Set Environment Variables**: \n    *   Replace `your_strong_db_password_here` with a secure password for the PostgreSQL database.\n    *   Replace `your_very_long_and_random_secret_for_nextauth` with a randomly generated, long string (e.g., using `openssl rand -base64 32`).\n    *   Update `NEXT_PUBLIC_APP_URL` to your actual server's IP address or domain if you plan to access it remotely or use reverse proxy.\n    *   If you wish to set up an initial admin user on first run, uncomment and set `INITIAL_ADMIN_EMAIL` and `INITIAL_ADMIN_PASSWORD`. **Remember to remove or comment these lines after the first successful login for security reasons.**\n4.  **Deploy**: Open your terminal, navigate to the directory where you saved `docker-compose.yml`, and run `docker compose up -d`.\n5.  **Access**: Once deployed, Linkwarden will be accessible via your browser at `http://your-server-ip:3000` (or the port you specified).
