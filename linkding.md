# Linkding\n\nLinkding is a self-hosted bookmark manager designed to store and organize your web links privately and efficiently. It offers a clean interface for tagging, searching, and filtering your bookmarks, complete with browser extensions for easy saving and import/export functionalities.\n\n## Prerequisites\n\nBefore deploying Linkding, ensure you have Docker and Docker Compose installed on your system. You will need to create a directory for Linkding's persistent data, for example, `linkding-data`, which will store its SQLite database and configuration.\n\n## Docker Compose Script\n\nHere's a production-ready Docker Compose script for Linkding:\n\n```yaml\nversion: '3.8'\n\nservices:\n  linkding:\n    image: sissbruecker/linkding:latest\n    container_name: linkding\n    restart: unless-stopped\n    ports:\n      - "9090:9090" # Host_Port:Container_Port - Access Linkding via http://your-server-ip:9090\n    volumes:\n      - ./linkding-data:/etc/linkding/data # Persistent storage for database and configuration\n    environment:\n      # Optional: Uncomment and configure if running behind a reverse proxy at a subpath (e.g., /linkding)\n      # - LD_CONTEXT_PATH=/linkding\n      # Optional: Set a custom root for media files (e.g., favicons, user avatars)\n      # - LD_MEDIA_ROOT=/etc/linkding/media\n```
