# Gatus\n\nGatus is an open-source health dashboard that vigilantly monitors the uptime and responsiveness of your self-hosted services, applications, and network endpoints. It provides real-time status updates and can send notifications when issues are detected, making it an essential tool for maintaining a reliable homelab or NAS environment.\n\n## Prerequisites\n\nBefore deploying Gatus, ensure you have:\n\n*   Docker and Docker Compose installed on your system (e.g., a Linux server, Synology NAS, or any compatible host).\n*   A directory structure for Gatus configuration, typically `./gatus/config.yaml` relative to your `docker-compose.yml` file.\n*   A `config.yaml` file defining the services you want to monitor. A basic example is provided below.\n\n## Docker Compose Script\n\nTo get started, create a `docker-compose.yml` file and a `gatus/config.yaml` file in the same directory. Replace the example `url` values in `config.yaml` with your actual service endpoints.\n\n### Example `gatus/config.yaml`\n\n```yaml\nendpoints:\n  - name: "Google Search"\n    url: "https://www.google.com"\n    interval: 10s\n    conditions:\n      - "[STATUS] == 200"\n      - "[RESPONSE_TIME] < 500ms"\n    ui:\n      group: "External Services"\n  - name: "Local Web Server"\n    url: "http://localhost:80" # Replace with an actual local service URL if available\n    interval: 15s\n    conditions:\n      - "[STATUS] == 200"\n      - "[RESPONSE_TIME] < 1000ms"\n    ui:\n      group: "Local Network"\n# Add more endpoints here to monitor your self-hosted applications\n# For more advanced configuration, including notifications, refer to the official Gatus documentation.\n```\n\n### `docker-compose.yml`\n\n```yaml\nversion: '3.8'\n\nservices:\n  gatus:\n    image: ghcr.io/twin/gatus:latest\n    container_name: gatus\n    restart: unless-stopped\n    ports:\n      - "8080:8080" # Gatus web interface\n    volumes:\n      - ./gatus/config.yaml:/config/config.yaml:ro # Mount the Gatus configuration file\n    # Uncomment the environment variable below if your config file is named differently\n    # or if you place it in a subdirectory within /config. The default is /config/config.yaml.\n    # environment:\n    #   - GATUS_CONFIG_FILE=/config/config.yaml\n\nnetworks:\n  default:\n    # Use an existing bridge network if Gatus needs to monitor other containers on it\n    # external: true\n    # name: my-docker-bridge-network\n    # Otherwise, a default bridge network will be created.\n    # If Gatus needs to reach services on your host machine, you might need to use host networking\n    # network_mode: host\n    # Or ensure your URLs in config.yaml use the host's IP address (e.g., http://192.168.1.10:3000)\n```\n\nTo deploy, navigate to the directory containing your `docker-compose.yml` and `gatus/config.yaml` files, then run:\n\n```bash\ndocker compose up -d\n```\n\nAccess Gatus by navigating to `http://your-server-ip:8080` in your web browser.
