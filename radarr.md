# Radarr\n\nRadarr is an independent fork of Sonarr redesigned to handle movies. It's a powerful movie collection manager for Usenet and BitTorrent users. It can monitor multiple RSS feeds for new movies, grab, sort, and rename them. It can also be configured to automatically upgrade the quality of existing movies when better releases are available.\n\n## Prerequisites\n\nEnsure you have a Docker environment set up. You'll need to create directories for Radarr's configuration, downloads, and your movie library.\n\n-   `./config`: Stores Radarr's application data and configuration files.\n-   `./downloads`: A shared volume where your download client places completed movie files. Radarr will process files from here.\n-   `./movies`: The root directory where Radarr will organize and store your movie collection.\n\nAdjust `PUID`, `PGID`, and `TZ` environment variables to match your system's user and group IDs, and your timezone, respectively.\n\n## Docker Compose Script\n\n```yaml\nversion: \"3.8\"\nservices:\n  radarr:\n    image: lscr.io/linuxserver/radarr:latest\n    container_name: radarr\n    environment:\n      - PUID=1000\n      - PGID=1000\n      - TZ=Etc/UTC\n    volumes:\n      - ./config:/config\n      - ./downloads:/downloads # This should be the same path as your download client for completed downloads\n      - ./movies:/movies # Your movie library root\n    ports:\n      - 7878:7878\n    restart: unless-stopped\n```
